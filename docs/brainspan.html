Data and migration notes

This page uses the expression, activity, phenotype, driver mappings, and network values from the original BrainSpan SQLite database. Values are not renormalized. Sample IDs, rather than row order, join profiles to metadata. Ages are the source Days values; the logarithmic axis and birth marker at day 266 follow the Shiny app.

The gene catalog is the existing SysNDD/SFARI/DBD NDD/ASD union, not a new disease-gene classification. Both source and target genes must belong to this union for a network edge to be exported. Non-NDD targets shown by the original app are intentionally excluded; an empty network does not imply no regulation.

Lines use browser-side local quadratic tricube regression on log10(age). Singular local fits reduce polynomial degree. Approximate 95% normal bands use local weighted residual variance and are omitted where variance is not estimable. They are not exact ggplot2 LOESS intervals, significance tests, or donor-adjusted inference. Fewer than four observations or three distinct ages receive no smooth. Samples can repeat donors; apparent precision should not be interpreted as biological replication.

Filters redraw the loaded profile immediately. Gene, driver, and profile changes require Draw. Downloads contain the filtered samples or selected driver's NDD-only edges; SVG replaces the server-generated PDF (browser print can save PDF). The Shiny group-comparison controls had no implemented analysis and are not reproduced.
