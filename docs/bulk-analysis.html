Data and interpretation

This page uses the copied expression/K-means v2 cluster assignments and enrichment CSVs. It shows exported cluster enrichment rows whose overlap gene list includes the selected gene; it does not calculate new gene-level enrichment tests.

GO and KEGG overlap lists use Entrez IDs, matched to gene symbols through a bundled mapping generated locally from org.Hs.eg.db. HPO uses gene symbols and includes the exported semantic community labels. GO ontology labels are BP (biological process), CC (cellular component), and MF (molecular function).

Header-only HPO files are empty results, not load errors. Cluster 10 has no exported HPO file. Neither condition is treated as evidence that a gene has no HPO annotations. GO and KEGG may use different backgrounds from HPO; their adjusted p-values should not be compared as if they were the same analysis. Disease pathways are annotation categories, not diagnoses.
